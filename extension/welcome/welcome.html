One quick check

Aligned works through notifications, so make sure Chrome is allowed to show them:

  1. Click the button below to send yourself a test reminder.
  2. If nothing appears: macOS — open System Settings → Notifications → Google Chrome, allow notifications, and choose the Alerts style so action buttons show. Windows — check Settings → System → Notifications, and that Focus Assist isn't blocking Chrome.
